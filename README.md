## 📊 Unidades Temáticas

El curso está organizado en los siguientes temas:

0. **Básicos de Estadística**
   - NumPy
   - Pandas
   - Matplotlib

1. **Regresión Lineal**
   - Scikit-learn
   - Statsmodels

2. **Regresión Logística**
   - Scikit-learn

3. **Árboles de Decisión**
   - Scikit-learn

## 🧰 Herramientas y Bibliotecas

Este curso utiliza las siguientes herramientas de Python para análisis de datos:

- **NumPy**: Computación numérica y operaciones con arrays
- **Pandas**: Manipulación y análisis de datos estructurados
- **Matplotlib**: Visualización de datos
- **Scikit-learn**: Algoritmos de machine learning (regresión lineal, regresión logística, árboles de decisión)
- **Statsmodels**: Modelado estadístico y pruebas
